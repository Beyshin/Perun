# Thermometer Case

## Required Parts:
- 9x M3 heat-set inserts
- 9x M3 5mm screws
- 4x AA battery holder (smaller battery holders can be used if paired with a step-up voltage converter)

## Print Settings & Materials:
- **Recommended material:** PETG / ABS / ASA (tested only with PETG)
- **Note:** The battery cover and internal divider must be printed using TPU 95A.
